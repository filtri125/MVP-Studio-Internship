# MVP-Studio-Internship
A collation of my projects that I have completed so far during my time volunteering at MVP Studio, a software start-up incubator.

## Australian Property Data
Completed the property analysis project comprising of three sprints: onboarding, competition, and advanced tasks.

For the onboarding task, I created an interactive Power BI dashboard that visualises Australian property data. In the competition tasks, I designed a snowflake schema data warehouse model utilizing SSIS data flows to load and transform location, school, and property data. Additionally, I developed an SSRS table report along with another Power BI dashboard for Australian school and property data. In the advanced tasks, I created load and staging tables for multiple datasets and designed a snowflake schema data warehouse model by adhering to the Kimball Methodology. Moreover, I developed multiple SSRS reports and interactive Power BI dashboards, which included hyperlinks in the form of a button, directing users to the corresponding SSRS report.
